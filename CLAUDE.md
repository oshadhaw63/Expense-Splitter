# CLAUDE.md

Before doing any work in this repository, read, in order:

1. [`AGENTS.md`](AGENTS.md) — binding operating rules for coding agents in this repo. Follow it in full; it is not summarised here.
2. [`docs/PROJECT_SPEC.md`](docs/PROJECT_SPEC.md) — what is mandatory, what is bonus, what is assumed, and the acceptance criteria the work is judged against.
3. [`docs/DECISIONS.md`](docs/DECISIONS.md) — the locked technical decisions (stack, money model, split rules, settlement algorithm) and why each was made.
4. [`docs/TEST_PLAN.md`](docs/TEST_PLAN.md) — the test suite the implementation must satisfy, split into a required core (Part A) and optional extras (Part B).

Do not start implementing, editing, or testing before reading all four. If anything you're about to do conflicts with what they say, resolve the conflict against these documents first — propose a documented change rather than silently diverging.
